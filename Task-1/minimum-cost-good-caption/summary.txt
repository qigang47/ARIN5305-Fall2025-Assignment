Implement minCostGoodCaption.
Input is lowercase; if n<3 return "".
Partition into blocks of size 3/4/5; each block becomes a single char repeated len. Block cost = sum |s[k]-ch|. Minimize total cost; tie by lexicographically smallest final string.
DP over suffixes (bottom-up):

Arrays: cost[n+1], takeLen[n+1], takeCh[n+1]; INF=1e9; cost[n]=0.
For i from n-1 downto 0:
If n-i<3: cost[i]=INF; continue.
bestCost=INF; bestL=0; bestC='a'.
For L in {3,4,5} with i+L<=n:
Compute blockCost and its optimal ch (try 'a'..'z'; on tie pick smaller ch).
If cost[i+L]==INF skip.
cand=blockCost+cost[i+L].
If cand<bestCost OR (cand==bestCost AND better(i,L,ch,bestL,bestC)):
bestCost=cand; bestL=L; bestC=ch.
Save cost[i]=bestCost; takeLen[i]=bestL; takeCh[i]=bestC.
If cost[0]==INF return "".
Lex tie comparator (uses choices already filled for indices > i; no nulls):
better(i,L1,c1,L2,c2):
p1=i; p2=i; r1=L1; r2=L2; a=c1; b=c2;
while (true):
if (a!=b) return a<b;
step=min(r1,r2); p1+=step; p2+=step; r1-=step; r2-=step;
if (r1==0) { if (p1==n) return false; a=takeCh[p1]; r1=takeLen[p1]; }
if (r2==0) { if (p2==n) return true; b=takeCh[p2]; r2=takeLen[p2]; }
Reconstruct:
For i=0 while i<n: append takeCh[i] exactly takeLen[i] times; i+=takeLen[i].
Time O(n263).
